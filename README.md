
# 💰 SmartSpend AI

## AI-Powered Personal Finance Management System

SmartSpend AI is a Python-based personal finance management system that helps users track income and expenses, categorize transactions, analyze spending patterns, monitor budgets, and receive personalized savings recommendations.

## 🎯 Problem Statement

Managing personal expenses manually can make it difficult to understand spending habits and identify areas where money can be saved.

SmartSpend AI solves this problem by combining data analysis with Generative AI to provide simple and useful financial insights.

## ✨ Features

- 💰 Income and expense tracking
- 🤖 AI-powered transaction categorization
- 📊 Category-wise spending analysis
- 📈 Spending visualization using charts
- 💵 Monthly budget management
- ⚠️ Budget warning system
- 🤖 AI-powered savings recommendations
- 🔄 Fallback system when the AI service is unavailable
- 📁 CSV-based transaction dataset
